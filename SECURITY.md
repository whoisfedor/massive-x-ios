# Security Policy

## Massive X — iOS Wallet

Security is a top priority for Massive X. As a non-custodial cryptocurrency wallet, the protection of private keys, transaction integrity, and user funds is essential.

We welcome responsible security research and vulnerability reports from the community.

## Supported Versions

Security reports are accepted for the latest maintained version of Massive X for iOS. Older versions may not receive security updates.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately.

**Email:** info@massive-x.com

Alternatively, use GitHub's private vulnerability reporting feature when available.

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The affected version or commit
- Potential security impact
- A proof of concept, if available

**Please do not disclose security vulnerabilities through public GitHub issues.**

We will review submitted reports and coordinate fixes and responsible disclosure where appropriate.

## Security Architecture

Massive X is designed around the following principles:

- Fully non-custodial wallet architecture
- Private keys stored locally using iOS Keychain protections
- Local transaction signing
- No private key transmission to intermediary servers
- Biometric authentication support
- Mainnet transaction validation and testing

## Security Audits

Massive X has undergone internal security reviews and automated testing.

**An independent third-party security audit has not yet been completed.**

Open-source publication is intended to improve transparency and enable community security review.

## Responsible Disclosure

We appreciate researchers who help improve Massive X security.

Please avoid accessing other users' data, disrupting services, or exposing vulnerabilities publicly before coordinated disclosure.

Thank you for helping make Massive X safer for everyone.
